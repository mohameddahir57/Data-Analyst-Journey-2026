# Excel Analysis Instructions

The `excel_reports` folder is where you should save your completed Excel workbooks (e.g., `.xlsx` files).

### How to Start:
1. **Copy the Data**: Take the raw data from `../data/Customer_Churn_Data.csv`.
2. **Open in Excel**: Open that CSV file and immediately "Save As" `Customer_Churn_Analysis.xlsx` inside this `excel_reports` folder.
3. **Tasks to Perform**:
    - **Clean Data**: Check for missing values in `TotalCharges`.
    - **Add Columns**: Create a `Churn Numeric` column (1 for Yes, 0 for No) for easier averaging.
    - **Pivot Tables**: 
        - Churn Rate by Gender.
        - Churn Rate by Service Type.
    - **Visualizations**: Create a Bar Chart for Churn by Service Type and a Pie Chart for overall Churn % .
